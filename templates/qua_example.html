Algebra: Quadratic Equation Examples

Example 1: \(3x^2 + 6x - 9 = 0\)

Solution:

$$ \begin{aligned} \text{Split the middle term:} \\ 3x^2 + 9x - 3x - 9 &= 0 \\ 3x(x + 3) - 3(x + 3) &= 0 \\ (3x - 3)(x + 3) &= 0 \\ \text{When } 3x - 3 = 0 &\Rightarrow x = 1 \\ \text{When } x + 3 = 0 &\Rightarrow x = -3 \\ \text{The required solutions are: } x = -3, 1 \end{aligned} $$

Example 2: \(x^2 - 7x + 6 = 0\)

Solution:

$$ \begin{aligned} \text{Split the middle term:} \\ x^2 - x - 6x + 6 &= 0 \\ x(x - 1) - 6(x - 1) &= 0 \\ (x - 6)(x - 1) &= 0 \\ \text{When } x - 6 = 0 &\Rightarrow x = 6 \\ \text{When } x - 1 = 0 &\Rightarrow x = 1 \\ \text{The required solutions are: } x = 1, 6 \end{aligned} $$

Example 3: \(2x^2 + 3x - 5 = 0\)

Solution:

$$ \begin{aligned} \text{Split the middle term:} \\ 2x^2 - 2x + 5x - 5 &= 0 \\ 2x(x - 1) + 5(x - 1) &= 0 \\ (2x + 5)(x - 1) &= 0 \\ \text{When } 2x + 5 = 0 &\Rightarrow x = -\frac{5}{2} \\ \text{When } x - 1 = 0 &\Rightarrow x = 1 \\ \text{The required solutions are: } x = -\frac{5}{2}, 1 \end{aligned} $$
